1️⃣ What is the difference between var, let, and const?

Ans:
var - is the function scoped, it can be redeclared and updated , It's is called global function.

let - is a block scoped , it can be updated but not can redeclared .

const - is a blocked scroped , it can't be updated or redeclared.

3️⃣ What is the difference between map(), filter(), and forEach()?
Ans:
map() → Creates a new array by transforming each element.
filter() → Creates a new array with elements that pass a condition.
forEach() → Loops through elements but does not return a new array
